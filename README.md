# Sleep-specialist referral packet: letter, questions and clinic checks

A sleep-specialist referral packet: a letter outline, first-appointment questions, and how to check a sleep clinic.

This is a free, standalone mini-resource. The live HTML page is intended to be served from:

- Render: `https://sleep-specialist-referral-packet.onrender.com/`
- GitHub Pages: `https://ahmetalkan.github.io/sleep-specialist-referral-packet/`

It cites public pages on [findsleepdoctors.com](https://findsleepdoctors.com/) and official reference sources listed at the bottom of the page. Nothing here is a substitute for advice from a qualified professional.
